## Claude Code 설치

Claude Code는 npm을 통해 설치합니다.

```bash
npm install -g @anthropic-ai/claude-code
```

## 인증 설정

설치 후 처음 실행하면 Anthropic 계정 인증이 필요합니다.

```bash
claude
```

터미널에서 위 명령어를 실행하면 브라우저가 열리고 로그인 화면이 나타납니다.

## 기본 사용법

프로젝트 디렉토리로 이동한 후 `claude` 명령어로 시작합니다.

```bash
cd my-project
claude
```
