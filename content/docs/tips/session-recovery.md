Claude Code 사용 중 실수로 Ctrl+C를 누르거나, 세션이 종료되는 경우가 있습니다. 두 상황은 대처법이 다릅니다. Interrupt는 그냥 이어서 말하면 되고, Exit은 `--resume` 플래그로 세션을 복구합니다.

---

## Interrupt (Ctrl+C) — 세션 유지됨

Ctrl+C를 누르면 **Claude의 현재 응답만 중단**됩니다. 세션 자체는 살아있습니다.

### 대처법

그냥 이어서 입력하면 됩니다.

```
계속해줘
```

```
중단된 부분부터 이어서 진행해줘
```

### 왜 문맥이 유지되나?

Claude Code(를 포함한 모든 LLM)는 대화를 "기억"하는 게 아닙니다. **매 응답마다 이전 대화 기록 전체를 다시 읽고 판단합니다.**

```
[사용자 메시지 1] → [Claude 응답 1] → [사용자 메시지 2] → [Claude 응답 2] → ...
       ↑_______________________________________________|
              매 응답마다 이 전체 기록을 다시 읽음
```

Interrupt가 되어도 세션 안에 대화 기록이 남아있으므로, 다음 입력 시 그 기록을 바탕으로 이어서 작업할 수 있습니다.

### 주의할 점

Interrupt 시점에 **파일이 절반만 수정된 상태**일 수 있습니다. 안전하게 이어가려면:

```
현재 파일 상태 확인하고, 중단된 작업 이어서 해줘
```

## Exit (세션 종료) — 세션 복구 필요

`/exit`을 입력하거나, 터미널 창을 닫거나, `claude`를 새로 실행한 경우입니다. 세션이 종료되면 대화 기록이 메모리에서 사라집니다.

### 대처법 1: `--resume`으로 세션 복구 (권장)

```bash
# 가장 최근 세션 이어서
claude --continue

# 세션 목록에서 선택
claude --resume
```

`--continue`는 마지막 세션을 바로 이어가고, `--resume`은 세션 목록을 보여줘서 원하는 세션을 선택할 수 있습니다.

### 대처법 2: 대화 중 `/resume`

이미 Claude Code를 실행한 상태라면 슬래시 명령어를 사용합니다.

```
/resume
```

세션 목록이 나타나고, 이어갈 세션을 선택하면 됩니다.

### 세션을 찾기 쉽게 — 이름 붙이기

작업 전에 세션에 이름을 붙여두면 나중에 찾기 쉽습니다.

```
/rename auth-refactor
```

또는 시작할 때 이름을 지정:

```bash
claude -n auth-refactor
```

## 한눈에 비교

| 상황 | 문맥 유지 | 복구 방법 |
|------|----------|----------|
| **Interrupt** (Ctrl+C) | ✅ 유지 | "계속해줘" 입력 |
| **Exit** (세션 종료) | ❌ 소실 | `claude --continue` 또는 `/resume` |

---

## 활용 가이드

- **긴 작업 전에는 `/rename`으로 이름을 붙여두세요.** Exit 후 `/resume`에서 "3시간 전 세션"보다 "auth-refactor"가 찾기 쉽습니다.
- **Interrupt 후에는 파일 상태부터 확인하세요.** 수정이 절반만 된 파일이 있을 수 있습니다.
- **대화가 길어지면 `/compact`도 고려하세요.** 세션을 이어가더라도 컨텍스트가 가득 차면 성능이 떨어집니다. `/compact`로 대화를 요약하면 컨텍스트를 확보할 수 있습니다.
